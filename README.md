filmweb-api 1.x (legacy)
========================

> **⚠️ Ta wersja nie jest już rozwijana i nie działa.** Korzystała z mobilnego API Filmweb
> (`ssl.filmweb.pl/api`), które zostało wyłączone.
>
> Aktualna wersja **2.x** (PHP 8.2+, REST API `www.filmweb.pl/api/v1`) jest na gałęzi
> [`master`](https://github.com/b44x/filmweb-api). Instrukcja migracji: [UPGRADE.md](https://github.com/b44x/filmweb-api/blob/master/UPGRADE.md).
>
> Jeśli mimo to potrzebujesz tej wersji: `composer require nsolutionspl/filmweb-api:^1.0`.

Projekt jest kontynuacją [filmweb-php](https://github.com/nSolutionsPL/filmweb-php).

Jako, iż Filmweb uruchomił API (nie)oficjalnie, z którego korzysta na urządzeniach mobilnych (np. Android/iOS).

Postanowiłem przepisać większość funkcji do PHP.
